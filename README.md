# Capability Models

What the organization has shown it can do: each closed-out project's delivered scope, actual cost
and schedule, labor and processes, and lessons learned, kept as a model of the organization's
capability to perform. Business development and solution architects use it for new business,
program managers for follow-on work, and it is the record an AI would ground a proposal in.
ISO/IEC/IEEE 15288 Organizational Project-Enabling: Knowledge Management (6.2.6).
